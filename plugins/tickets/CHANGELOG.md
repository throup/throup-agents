# Changelog

All notable changes to the `tickets` plugin. Versions follow [semver](https://semver.org/).

## 0.1.1

- `write-ticket`: evidence is re-run against the pinned base before it is written down, and a
  finding's scope is what that re-run shows, not what a review reported.

## 0.1.0

- `write-ticket`: write, reshape or merge a ticket so a product owner reads the title, two
  paragraphs and the acceptance criteria, and an implementer finds everything else in one
  collapsed block.
